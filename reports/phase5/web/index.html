How to read the two filters above

CONFIDENCE TIER — how many methods agree
3 methods (critical) — IQR, Z-score, and Isolation Forest all flagged this record — the strongest possible signal.
2 methods (robust) — Two of the three agree — still trustworthy, since the methods answer different questions (see Jaccard overlap below).
1 method — Only one method flagged it — could be real, could be that method's own blind spot.
not flagged — None of the 3 methods flagged this record.
DETECTOR METHOD — which one, specifically
IQR — Univariate fence, 1.5× the interquartile range on one raw variable at a time (loan amount, income, property value, or interest rate). Simple, but blind to combinations.
Z-score — Univariate too (|z| > 3 on the same 4 variables), but stricter — extreme values inflate the mean/std they're measured against, so fewer records qualify.
Isolation Forest — The only multivariate method: runs on all 37 standardized features at once, catching records whose combination of attributes is unusual even when no single value is extreme.
