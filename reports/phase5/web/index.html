How to read the two filters above

glossary

Two independent questions about the same record: "how many methods agree" (Confidence tier) and "which method(s) specifically" (Detector method). Combine both — e.g. tier "3 methods" tells you all 3 fired, but only the Detector method chips tell you those 3 are IQR, Z-score, and Isolation Forest, not just a count.

CONFIDENCE TIER — how many methods agree
3 methods (critical) — IQR, Z-score, and Isolation Forest all flagged this record — the strongest possible signal.
2 methods (robust) — Two of the three agree — still trustworthy, since the methods answer different questions (see Jaccard overlap below).
1 method — Only one method flagged it — could be real, could be that method's own blind spot.
not flagged — None of the 3 methods flagged this record.
DETECTOR METHOD — which one, specifically
IQR — Univariate fence, 1.5× the interquartile range on one raw variable at a time (loan amount, income, property value, or interest rate). Simple, but blind to combinations.
Z-score — Univariate too (|z| > 3 on the same 4 variables), but stricter — extreme values inflate the mean/std they're measured against, so fewer records qualify.
Isolation Forest — The only multivariate method: runs on all 37 standardized features at once, catching records whose combination of attributes is unusual even when no single value is extreme.

Method agreement (pairwise overlap)

Jaccard similarity

How much each pair of detection methods agrees on which records are anomalous — "both" = flagged by both methods, "either" = flagged by at least one, Jaccard = both ÷ either. Low Jaccard means the 3 methods are answering different questions, not being redundant.

The imputation-artifact correction

data-quality finding

Dataset-wide, income is imputed in 11.5% of the 100,000-row sample and property value in 22.5% — but that rate is far from even across segments (2–87% for income, 4–55% for property value; see the segment signal matrix above), which is exactly why it distorts some segment medians and not others.

71.5% of the 228 records flagged by all 3 methods carried an imputed, not genuinely reported, income or property value — a placeholder inserted for missing data during cleaning. Because expm1(log1p(x)) == x exactly, an imputed value reconstructs to precisely the sample mean, making it a checkable fingerprint. This finding revised two Phase 2 segment profiles: the "Purchased" segment's true median income is $107,000 (not $163,500 as first reported), and the "Withdrawn" segment's true median property value is $435,000 (not $554,000).
